DUBWISE

Install on your FM-1

  1. From The Firmware Hub (once listed): open thefirmwarehub.com, find DUBWISE, and install it with one click over USB.
  2. Or by hand: download dubwise-X.Y.fwsc from the releases, then run python3 base/tools/fm1_install.py dubwise-X.Y.fwsc from a clone of the repository (it needs pip install mido python-rtmidi).

After the restart the FM-1 shows the SpIllt Beats mark, then the DUB page. Press PLAY.

Installing custom firmware is at your own risk. Dubwise carries the update loader, so you can always install the stock firmware (or another one) over it again.
